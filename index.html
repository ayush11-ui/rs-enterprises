For the site owner: how the Google Form was set up
The exact steps to create the form
  1. Go to forms.google.com and create a new form, titled "RS Enterprises - Job Application Form".
  2. In the form Settings, turn on "Collect email addresses" (optional). In the Responses tab, click the green Sheets icon once, so a linked Google Sheet is created. Every submission will be saved there automatically and permanently - nothing is lost even if this website ever has a problem.
  3. Add every field listed in the 'Application form fields' box below as a question, in both English and Hindi. Use Section breaks so the form stays short, neat and easy to read.
  4. Get the embed code: click "Send" (top right), then the "" Embed icon, and copy the iframe code.
  5. Paste the iframe code into index.html, in the dashed form box where the owner note says: PASTE GOOGLE FORM EMBED IFRAME CODE HERE
  6. Replace [PASTE GOOGLE FORM LINK HERE] on this page with the form's direct link (Google Forms -> Send -> Link).
